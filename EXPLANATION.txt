This document explains the specific use, input, output, and analytical purpose

--------------------------------------------------------------------------------
1. CORE TECHNOLOGIES & VIVA SUMMARY
--------------------------------------------------------------------------------

- HDFS      -> Stores raw and processed electronics datasets (/ecommerce/raw/).
- YARN      -> Manages Hadoop cluster CPU and RAM container resources.
- PySpark   -> Cleans, aggregates, and processes transactions in parallel.
- RFM       -> Measures Recency (days), Frequency (orders), Monetary ($ spend).
- K-Means   -> Groups customers into 4 behavioral segments (Champions, Loyal, At Risk, Lost).
- app.py    -> Multi-threaded Python REST server providing JSON data to frontend.
- React     -> Displays interactive analytics, charts, and customer segment tables.
- Docker    -> Orchestrates containerized Hadoop NameNode, DataNode, YARN, Runner, UI.

--------------------------------------------------------------------------------
2. ROOT EXECUTABLE FILES & SERVERS
--------------------------------------------------------------------------------

2.1 `run_pipeline.py`
    - Use: Execute the master data processing pipeline.
    - Command: `python run_pipeline.py`
    - Function: Invokes `src/main.py` which runs data generation, HDFS storage, 
      cleaning, RFM segmentation, and K-Means clustering.
    - Output: Generates CSV and JSON output files in `output/` and `data/processed/`.

2.2 `app.py`
    - Use: Launch the Web Dashboard API & Static File Server.
    - Command: `python app.py` (Server runs at http://localhost:8501)
    - Function: Exposes `/api/data` JSON endpoint and serves built React static 
      assets from `frontend/dist/`.

2.3 `requirements.txt`
    - Use: Define Python library dependencies (`pyspark`, `pyarrow`, `pandas`, 
      `numpy`, `scikit-learn`, etc.).

2.4 `README.md`
    - Use: Detailed project overview, architectural description, setup guide, and 
      viva explanation script.

--------------------------------------------------------------------------------
3. BACKEND ANALYTICS ENGINE (`src/` MODULES)
--------------------------------------------------------------------------------

3.1 `src/main.py`
    - Use: Orchestrate end-to-end analytical workflow execution.

3.2 `src/data_loader.py`
    - Use: Electronics E-Commerce Data Generator.
    - Function: Generates products across 9 electronics categories (Smartphones, 
      Laptops, Headphones, Keyboards, Mouse, Monitors, Smartwatches, Tablets, Chargers), 
      customer profiles, transactions, and clickstream logs.

3.3 `src/data_cleaning.py`
    - Use: Data Sanitization and Aggregation Engine.

3.4 `src/rfm_analysis.py`
    - Use: RFM Scoring & 3D K-Means Clustering Model.

3.5 `src/segmentation.py`
    - Use: Rule-based RFM segment assignment helper.

3.6 `src/hadoop_hdfs_helper.py`
    - Use: HDFS CLI integration & dataset uploader helper.

--------------------------------------------------------------------------------
