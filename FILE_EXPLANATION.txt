ELECTRONICS E-COMMERCE BIG DATA ANALYTICS PROJECT - FILE EXPLANATION

This project analyzes customer behavior in an Electronics E-Commerce Store
selling Smartphones, Laptops, Headphones, Keyboards, Mouse, Monitors, Smartwatches,
Tablets, and Chargers.

============================== 1. Main Project Files
==============================

run_pipeline.py

Starts the complete data pipeline: Data Loader -> HDFS -> PySpark -> Data Cleaning -> RFM Analysis -> K-Means -> Customer Segmentation.

app.py

Starts the Python Web Dashboard server at http://localhost:8501. Serves JSON API endpoints and React frontend.

requirements.txt

List of Python dependencies (pyspark, pyarrow, pandas, numpy, scikit-learn).

README.md

Main documentation with Viva explanation script, architecture flowchart, and setup instructions.

============================== 1b. Docker & Hadoop Infrastructure
==============================

docker-compose.yml

Orchestrates multi-container Hadoop cluster (NameNode, DataNode, YARN ResourceManager, NodeManager, Pipeline Runner, and Web Dashboard).

Dockerfile

Defines container environment with OpenJDK 11, Hadoop 3.3.6, and Python 3.10.

entrypoint.sh

Formats HDFS, initializes services based on role, and launches the pipeline.

hadoop-config/

Contains core-site.xml, hdfs-site.xml, and yarn-site.xml configuration files.

src/hadoop_hdfs_helper.py

Manages HDFS commands and uploads dataset to /ecommerce/raw/.

============================== 2. Source Code Folder (src)
==============================

main.py

Master pipeline execution controller.

data_loader.py

Generates synthetic datasets for Electronics Store (Smartphones, Laptops, Headphones, Keyboards, Mouse, Monitors, Smartwatches, Tablets, Chargers).

data_cleaning.py

Cleans transaction line items, removes invalid values, and aggregates customer metrics.

rfm_analysis.py

Computes Recency, Frequency, and Monetary scores (1-5 scale) and runs K-Means clustering.

segmentation.py

Assigns behavioral segment labels (Champions, Loyal Customers, At Risk, Lost Customers).

visualization.py

Prepares JSON payloads and summary reports.

============================== 3. Frontend Folder (frontend)
==============================

App.jsx

Main React component managing views.

PipelineFlow.jsx

Visual 11-step architecture flowchart banner.

ExecutiveOverview.jsx

Displays sales, revenue, active accounts, and customer segment doughnut chart.

RFMTable.jsx

Explores individual customer RFM scores and K-Means clusters.

RawDataViewer.jsx

Browses live dataset rows.

HadoopCluster.jsx

Inspects live NameNode, DataNode, YARN status, and HDFS file paths.

Sidebar.jsx & Header.jsx

Navigation menu and header status badges.
